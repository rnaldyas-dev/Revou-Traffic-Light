# Traffic Light README Design

- **Intent:** Give beginners a friendly, easy-to-follow introduction to the traffic-light simulator and how to try it.
- **Goals:** Explain what the project does, identify its files, and show how to open and use it without extra setup.
- **Non-goals:** Add features, dependencies, or setup tooling; change the simulator's behavior.
- **Constraints:** The project is a standalone `index.html` and `app.js`; the yellow light currently stays on for one second before switching between red and green.
- **Approaches:** A concise overview is quickest to scan; a beginner walkthrough explains the project and usage step by step; a portfolio-style README emphasizes learning outcomes. Use the beginner walkthrough, as selected, because the target reader is new to the project.
- **Builder calls:** Write in Indonesian with a casual, clear tone; state that opening `index.html` in a browser is sufficient; describe only behavior confirmed by the current files.
