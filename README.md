# Traffic Light Simulator

Halo! Ini proyek sederhana untuk mencoba simulasi lampu lalu lintas di browser.

## File proyek

- `index.html` menampilkan lampu lalu lintas dan tombol untuk mengganti lampu.
- `app.js` mengatur urutan perubahan lampu.

## Cara menjalankan

Pastikan kedua file berada di folder yang sama, lalu buka `index.html` langsung di browser. Tidak perlu menginstal apa pun.

## Cara kerja

Saat halaman dibuka, lampu merah menyala. Klik tombol **Switch Traffic Light** untuk memulai pergantian. Lampu kuning menyala selama satu detik, lalu lampu berganti dari merah ke hijau atau dari hijau ke merah. Setiap klik berikutnya mengulangi pergantian tersebut.
